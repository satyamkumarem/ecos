An proctored examination and code practice environment designed to combine test security with computational efficiency.

---

## Introduction

Online proctoring systems often struggle to balance security, performance, and accessibility. High resource consumption, downtimes due to traffic, heavy cloud computing costs, and easily bypassable detection mechanisms leave both institutions and candidates frustrated.

**ECOS** (Examination & Coding Operations Suite) is being built to address these challenges. Our goal is to build an lightweight, and proctored examination environment and coding practice platform designed to prevent real-world cheating techniques while remaining cost-effective to deploy at scale.

> **Status Notice:** ECOS is currently in the active architectural and planning phase. Detailed system design documents, API specifications, and roadmap milestones.

---

## Agenda & Plans

* **Architecture Design:** Finalizing low-latency client monitoring protocols and resource-efficient server infrastructure.
* **On-Device Evaluation Models:** Offloading core detection logic directly to client hardware to eliminate massive cloud streaming bandwidth and GPU costs.
* **Security & Anti-Bypass Framework:** Researching common software, hardware, and virtual machine bypass methods to design a robust anti-cheating environment.
* **UI/UX Refinement:** Crafting an intuitive, non-intrusive examination interface that reduces test-taker anxiety while maintaining strict compliance.

### What We Are Looking For:

* **Cost-Effective Proctoring:** Innovative approaches to proctor testing sessions without incurring unsustainable cloud processing costs.

* **Real-World Bypass Insights:** Explanations of methodologies currently used to bypass existing proctoring tools and technical recommendations on how to counter them effectively.

## Contribution Requirements

We welcome passionate contributors across UI/UX design, backend development, and field testing. Please review the specific qualification criteria for each area below before applying:

### 1. UI/UX Designers

* **Experience:** Must possess verified experience in user interface and user experience design.
* **Portfolio Requirement:** Strictly **no AI-generated slop** or generic AI-prompted mockups. We evaluate genuine, human-crafted design systems, user flows, and wireframes.
* **Application:** Please submit your resume and verified portfolio directly to **`career@euome.com`**.

### 2. Backend Engineers

We are seeking engineers to work on secure execution, sandbox, and evaluation systems. Key technical requirements include:

* **Obfuscation Strategies:** Techniques for binary/code obfuscation, anti-tampering, and runtime memory protection.
* **Containerization:** Hands-on experience with container environments (Docker, container isolation, process sandboxing).
* **On-Device Evaluation:** Implementing performant local checks and ML/statistical evaluation on client devices.
* **Tech Stack:** Proficiency in **Node.js** and **TypeScript**.
* **Application:** Please submit your resume and code samples/portfolio directly to **`career@euome.com`**.

### 3. QA Testers

* **Eligibility:** Must be currently enrolled in any academic program or course at **Lovely Professional University (LPU)**.
* **Role:** Conducting live test passes, testing edge cases across varied network conditions, and attempting benign environment bypasses to evaluate platform stability and security.
* **Application:** Please submit your details and contact us using **`contact@euome.com`**.
